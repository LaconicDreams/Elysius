## Tools (instance folder)
- `check-mods.ps1`: reads every jar's mods.toml and reports missing dependencies and version mismatches
- `questtools/questgen.py`: data table that generates **all** FTB Quests chapters. Edit this file, not the .snbt files. IDs are kept in `ids.json`.
- `questtools/validate.py`: quest checker. Runs as Prism's pre-launch command and cancels the launch on errors. Also checks the TaCZ loot pack.
- `questtools/balance.py`: economy auditor (`balance_report.txt`)
- `questtools/dungeongen.py`: writes the `elytra_dungeons` boss-dungeon datapack (structures as NBT, worldgen JSON, functions, loot). `packcheck.py` checks it before launch.
- `questtools/lootgen.py`: writes `minecraft/tacz/elytra_loot` (TaCZ loot injectors, 5 chest tiers, `loot_report.txt`)
- `devnotes/`: phase reports and the Chunky command list. `CHANGELOG.md` lists every changed file.

## Config and settings
- `config/curios-common.toml`: slots = ["id=back;size=2"] (elytra and Traveler's Backpack share the Back slot)
- Friendly fire: vanilla team "friends"
- Reload quests in game with /ftbquests reload (OP). FTB re-saves all chapter files when it does; questgen treats those as in-game edits.
- options.txt: render distance 16, simulation distance 8 (6 recommended)

## FTB Quests
- 24 chapters in config/ftbquests/quests/chapters/, all generated by questgen.py
- Shop chapters: bulk ammo = one stack of that calibre (stacks are 64/60/48/42/36/30/6, not always 64); popups are off (`disable_toast`)
- FTB only accepts IDs up to 7FFFFFFFFFFFFFFF; questgen and the validator enforce this
- Format: tab-indented, 16-hex uppercase IDs, & escaped as \\& in the file, 0.0d / 3L / 1b
